# Java Programming Projects

A collection of Java programming exercises organized by introductory computer science course. The repository preserves coursework and practice code demonstrating core programming concepts.

## Organization

- **CPSC 1210 — Introduction to Computer Science I**
- **CPSC 1220 — Introduction to Computer Science II**

Each course folder contains its associated exercises and project work.

## Technology

- Java
- Object-oriented programming
- Core data structures and programming fundamentals

## Run locally

1. Install a current Java Development Kit (JDK).
2. Clone the repository.
3. Open the project or source folder in an IDE such as IntelliJ IDEA or VS Code with Java support.
4. Compile and run the desired class, following any package or project-specific instructions.

For a simple standalone source file:

```bash
javac Example.java
java Example
```

The command may need to be adjusted for package declarations or project structure.
